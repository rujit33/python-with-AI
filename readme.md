# Assignments

Each assignment is fully self-contained inside its respective folder.

Every assignment includes its own comprehensive `README.md` file containing:

- project overview
- setup instructions
- dependencies
- usage guide
- implementation details

---

# Setup

## 1. Clone the Repository

```bash
git clone <repository-url>
```

---

## 2. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3. Navigate to the Assignment Folder

```bash
cd "folder-name"
```

---

## 4. Follow the Assignment Instructions

Refer to the `README.md` file inside the selected assignment folder for:

- installation steps
- execution commands
- project-specific configuration
- usage instructions
